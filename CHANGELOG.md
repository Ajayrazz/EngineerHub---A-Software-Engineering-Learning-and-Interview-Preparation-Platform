## [Unreleased]
### Added
- Initial product, requirements, architecture, security and roadmap documentation (docs 00–19).
- Docs 20 (content & licensing policy) and 21 (Razorpay payments & GST design).
### Fixed
- **Nav/footer link prefetching (2026-11-25):** the signed-in header now asks the API who you are (staff or learner), so Next.js prefetching every nav/footer link made background server renders refresh the access token. That raced with the Keycloak-outage browser test (it saw 200 instead of 503) and wasted API calls. Nav and footer links no longer prefetch; the outage test passes again, locally and in CI.
### Added
- **Database backups (2026-11-25):** `make db-backup` dumps the local application and Keycloak databases to the git-ignored `./backups`, and `make db-restore-check DUMP=...` restores a dump into a throw-away database and compares every table's row count with the live one (verified for both databases: identical counts). The original course and problem content also lives in git (`content/*.json`) and can be re-seeded with `make seed-content`.
